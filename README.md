# Laboration 4 i C#
Uppgiften har gått ut på att bygga en konsolapplikation med supervised learning, alltså en applikation som kan göra förutsägelser utifrån ett dataset.

I denna applikation har datasetet Titanic-Dataset.csv använts.

## Krav:
- Applikationen ska fråga efter relevanta egenskaper (feastures) som anses vara av vikt för att göra bra förutsägelser.
- Data ska delas upp i test- och träningsdata för att kontrollera modellen.
- Modeller tränas på träningsdata, testas av testdata innan användning av konsolprogrammet
